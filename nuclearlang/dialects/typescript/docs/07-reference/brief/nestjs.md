# Dialect `nestjs`: the backend platform in TypeScript

What this dialect adds to the platform's sheet: the project is generated as NestJS 12 (ES modules) + Sequelize +
class-validator + LangChain.js in `build/` (never edit it). `nuclear build`, `nuclear install` (npm),
`nuclear run` (node --watch), `nuclear test` (node:test), `nuclear migrate`. Full rules: `nuclear help nestjs`.

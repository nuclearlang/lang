# The `python` dialect

How Nuclear is written in Python: typed Python 3.12+ that passes `pyright --strict`. Its framework dialect,
`fastapi`, writes the [backend platform](../../../nuclear-synapsis-framework/platforms/backend/AGENTS.md) of
Synapsis with FastAPI.

## Why it exists

So that the same Nuclear runs where Python is the right target, without the Nuclear bending to Python. The `.nuc`
keeps Nuclear's `camelCase`; the dialect writes Python's `snake_case`, and keeps as they are the names that exist
that way in the type definitions. The library is Nuclear's: every member of Nuclear's standard library has its
Python template in `library.toml`, and a Python name such as `len` or `append` in Nuclear code is a bug. It leaves out what the
platform's contract does not have: `fastapi` only writes the kinds, decorators and folders of the backend platform.

## How we made it

- **A dialect made with the dialect system, with no Python in Rust.** Everything Python needed (lambdas with a
  block hoisted to local functions, f-strings, constructor defaults, `snake_case` names) became generic emitter
  options any later target can use ([ADR-python-0001](docs/03-adr/0001-python-dialect-and-generic-emitter-options.md)).
- **The target**: PEP 8 layout (4 spaces, 88 columns, two blank lines), PEP 695 generics, docstrings, and a
  `Result` runtime written into the file (ADR-python-0001).
- **`fastapi`**: FastAPI controllers, SQLAlchemy 2 async repositories, pydantic models, LangChain / LangGraph
  agents and graphs, aiokafka and `redis.asyncio`, over the platform's runtime package `synapsis-py`
  ([ADR-python-0002](docs/03-adr/0002-fastapi-dialect.md)).
- **Type definitions** are generated by `../../tools/defs/python/` with `inspect` from a pinned virtual environment:
  `python@3.14` for this dialect, and 18 more packages for `fastapi` (`nuclear defs list --dialect fastapi`).

It is data only: `dialect.toml`, `keywords.toml`, `library.toml`, `docs.toml`, `templates/`, `frameworks/fastapi/`
and the generated `defs/`, read at run time by the compiler ([../../](../../README.md)).

## Try it

From the root of the tree (or with the installed `nuclear`). Save as `hello.nuc`:

```
fullName(firstName: string, lastName: string) string
  "${firstName} ${lastName}"
```

```sh
cargo run -q -p nuclear-cli -- build hello.nuc --dialect python
#   from __future__ import annotations
#
#
#   def full_name(first_name: str, last_name: str) -> str:
#       return f"{first_name} {last_name}"
cargo run -q -p nuclear-cli -- dialect check fastapi       # dialect 'fastapi' (fastapi → python) is valid: 16 kinds, ...
cargo run -q -p nuclear-cli -- defs show Path --dialect python   # pathlib's Path in Nuclear notation
cargo run -q -p nuclear-cli -- spec --brief --dialect fastapi    # the short sheet an agent reads
cd nuclearlang && tools/spec-check/check.py dialects/python/docs/07-reference/python.md python python
#   dialects/python/docs/07-reference/python.md: 17 equivalences, 0 problems
```

A whole backend (`pyright --strict`, pytest and a live run):
`nuclear-synapsis-framework/platforms/backend/checks/fastapi-check/check.sh`.

# A frame over the WebSocket that is JSON and not an object
security ws.frame.binary | a binary frame: fastapi closes abnormally with a stack, nestjs closes 1003
security ws.frame.headers.not.object | `headers` that is a text: fastapi sends no answer (a task's exception never retrieved), nestjs answers 200
security ws.frame.method.unknown | an unknown method: fastapi 405, nestjs 400 with no body
security ws.frame.path.number | `path` that is a number: fastapi 404, nestjs 500
security ws.frame.deep.body | a body 50 000 levels deep in a frame: fastapi closes the socket abnormally (RecursionError), nestjs answers 500
security ws.frame.number | fastapi closes the socket abnormally with a stack; nestjs ignores the frame
security ws.frame.deep | 50 000 levels: fastapi closes the socket abnormally (RecursionError); nestjs ignores the frame
security ws.frame.null | nestjs: the frame `null` ends the process (an uncaught TypeError in the message handler); fastapi closes the socket with a stack

# A request of the WebSocket that leaves the app (nestjs writes the frame's path after its own address)
security ws.path.userinfo | the path `@host/x`: fastapi 404, nestjs 500 (its HTTP client refuses a URL with credentials: nothing left the app)
security ws.path.absolute | an absolute URL as the path: fastapi 404, nestjs 500 (nothing left the app)
security ws.path.port.suffix | nestjs: the path `<digit>/x` is sent to the port <app's port><digit> of this machine, with the upgrade's headers (the token), and its answer returned; fastapi 404

# The WebSocket's upgrade
security ws.upgrade.none | a refused upgrade answers 403 in fastapi (whatever the guard) and 401 in nestjs
security ws.upgrade.wrong | a refused upgrade answers 403 in fastapi (whatever the guard) and 401 in nestjs
security ws.upgrade.query | a refused upgrade answers 403 in fastapi (whatever the guard) and 401 in nestjs
security ws.upgrade.other.path | an upgrade on a path that is not the socket's: fastapi refuses it (403), nestjs never answers and keeps the connection open
security ws.upgrade.path.slash | the same for `/ws/`

# The body limits differ: none in fastapi, 100 KB in nestjs
security body.200KB | fastapi reads the whole body, nestjs answers 413 `request entity too large`
security body.2MB | fastapi reads the whole body, nestjs answers 413 `request entity too large`
security body.30MB | fastapi reads and parses a body of 30 MB (then refuses the field's length); nestjs answers 413 from 100 KB
security body.note.1MB | a text of 1 MB in a field without a rule: fastapi 500 (longer than its column), nestjs 413
security ws.frame.1MB | a frame of 1 MB: fastapi reads it (400, the field is too long), nestjs answers 413
security ws.frame.20MB | a frame of 20 MB: fastapi closes the socket 1009 (its limit is 16 MB), nestjs reads it (its limit is 100 MB) and answers 413

# What the app logs
logs fastapi.500.values | the stack fastapi logs for a 500 holds values a client sent (`[parameters: (...)]` of a database error, `input_value=` of a model)
logs fastapi.requests.query | fastapi's line of a request holds the whole query
logs nestjs.requests.silent | nestjs logs no line for a request; fastapi one (address, method, path with its query, status; no time): the logs cannot be compared
logs nestjs.500.silent | nestjs logs nothing for a 500: the client is told `error` and the cause is nowhere; fastapi logs the stack
logs nestjs.colours | nestjs writes the terminal's colour codes into a log that is a file

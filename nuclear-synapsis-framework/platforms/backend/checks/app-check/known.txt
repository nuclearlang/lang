# An `int` holds 64 bits in a request; its column holds what the database's INTEGER holds (32 bits on PostgreSQL,
# MySQL and MariaDB): a larger one is refused by the database (500, both dialects) and kept by SQLite
security int.beyond32@postgres | an `int` of 2^31 in a body: 500 in both on PostgreSQL (201 on SQLite): the column is 32 bits (the roadmap: the columns of an `int`)
# TypeScript's numbers hold 53 bits exactly: a larger whole number is rounded before the app sees it
security body.number.precision | an `int` of 2^53 + 1: fastapi 500 on PostgreSQL (beyond its 32-bit column), nestjs rounds it (`Customer 9007199254740992 not found`)

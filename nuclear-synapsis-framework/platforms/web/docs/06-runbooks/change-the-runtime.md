# After changing the runtime

The steps after a change in `packages/dragonfly-web`. Commands run from the root of the tree; the set-up is in
[testing](../05-standards/testing.md).

## 1. Build and test the runtime alone

```sh
(cd nuclear-synapsis-framework/platforms/web/packages/dragonfly-web && npm install && npx tsc -p tsconfig.json && npx vitest run)
```

## 2. Install it where the check reads it

The runtime is copied into `nuclearlang/tools/node/node_modules`, never linked, and the copy is repeated after
every rebuild. The check does it; by hand:

```sh
(cd nuclearlang/tools/node && npm install && npm install --no-save --install-links ../../../nuclear-synapsis-framework/platforms/web/packages/dragonfly-web)
```

## 3. Run the check

```sh
sh nuclear-synapsis-framework/platforms/web/checks/react-check/check.sh
```

## 4. A changed public API: regenerate the type definitions

The compiler and the editors know the names of the runtime, of React and of the test libraries from
`nuclearlang/dialects/typescript/defs/{react,react_router,vitest,testing_library_react,dragonfly-web}/<version>/`.
They are generated by `nuclearlang/tools/defs/typescript/gen.js` from `nuclearlang/tools/node/node_modules` (React
and the test libraries are installed there; the runtime by step 2, after its build):

```sh
node nuclearlang/tools/defs/typescript/gen.js <name> <version> <out-root> [<module>...] [--depends a@1,b@2] [--description "..."]
# writes <out-root>/typescript/<name>/<version>/{package.toml,index.json,api.json}; copy it into nuclearlang/dialects/typescript/defs/
```

The arguments each of the five packages was generated with can be read back from its `package.toml` (`name`,
`version`, `libraries` = the modules, `depends`, `description`); for the runtime: modules `dragonfly-web` and
`dragonfly-web/testing`, depends `typescript@<v>,react@<v>`. `nuclearlang/tools/defs/typescript/generate.sh`
regenerates the TypeScript standard library and the backend's packages only.

## 5. The golden, the documents, the installed copy

- The generated output changed: `UPDATE_GOLDEN=1 cargo test`, and review the diff.
- A change a user can see: `docs/07-reference/web.md` gets the Nuclear, the dialect's reference its output,
  `CHANGELOG.md` a line.
- `installer/install.sh`: the installed `dragonfly` installs the runtime into a project from the installation's
  `packages/`, so a project of the user sees the change only after it.

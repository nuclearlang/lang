# Nuclear UI Designer

**Not built.** A builder of UI inside VS Code: screens and widgets drawn and edited visually, and written back as
Nuclear.

## What exists today

No code and no spec. The Nuclear workspace of VS Code has a template tab, *UI designer* (`Ctrl+Alt+D`): a page that
says what the tool will do and lists as planned a canvas of the active screen built from its `.nuc`, dragging
widgets from the platform's kinds, and two-way editing (the code changes, the canvas follows).

# Nuclear Builder: the guides

Nuclear Builder takes a spec through specification, generate, plan, tests first, code, verification, security,
artifacts and deploy, on your machine, and shows who did each step. It is the tool *Nuclear Builder* of the Nuclear
workspace in VS Code (`Ctrl+Alt+P`), a tool window in Android Studio / IntelliJ (`Alt+Shift+P`), and the
`nuclear-builder` command in a terminal or a CI job. It needs the Smart Graph and the Nuclear Developer running
([Set up the AI services](../../../../../installer/docs/08-guides/ai-setup.md)).

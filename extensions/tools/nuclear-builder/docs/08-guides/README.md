# Nuclear Builder: the guides

Nuclear Builder takes a spec through specification, generate, plan, tests first, code, verification, security,
artifacts and deploy, on your machine, and shows who did each step. It is the tool *Nuclear Builder* of the Nuclear
workspace in VS Code (`Ctrl+Alt+P`), a tool window in Android Studio / IntelliJ (`Alt+Shift+P`), and the
`nuclear-builder` command in a terminal or a CI job. It needs the Smart Graph and the Nuclear Developer running
([Set up the AI services](../../../../../installer/docs/08-guides/ai-setup.md)).

| Guide | Read it to… |
|---|---|
| [Write a spec and start the Builder](write-a-spec.md) | write a spec in VS Code, JetBrains or a terminal, and start a run |
| [Follow a run](follow-a-run.md) | follow a run, run something again, read a failure |
| [The pipeline's commands, locally and on a server](pipeline-commands.md) | change the commands of each stage, export them to CI |
| [Make a team](make-a-team.md) | make a team with the wizard: its name, purpose and skills, the members suggested and chosen, who works each one and what it costs |
| [Read what the factory spent and made](read-the-reports.md) | read the bill of tokens and money and the reports of the work (throughput, cycle time, burndown, flow, waiting gates, quality, each member), in VS Code, a terminal or from an agent |
| [Ask the team to do it](ask-the-team.md) | have the team read your slides, write the specs and run them from the chat; what it never decides alone |

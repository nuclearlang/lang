# Decisions of the editor extensions

The decisions about the editors: the three extensions and their tools (the tools have no key of their own). Cited
as `ADR-extensions-NNNN`. The format is [the platform's template](../../../docs/03-adr/0000-template.md). An accepted
ADR is not edited: a new one replaces it.

| ADR | Decision | Status |
|---|---|---|
| [ADR-extensions-0001](0001-one-base-extension-per-editor.md) | One language server and one base extension per editor; a framework's tools go in an extension of that framework | accepted |
| [ADR-extensions-0002](0002-the-nuclear-workspace.md) | The Nuclear workspace in the editor: projects and tools as tabs, one thing on screen, keyboard first | accepted |

A decision cited by its old platform-wide number (`ADR-00NN`, in code or commits before 2026-11-16): see
[the table of old numbers](../../../docs/03-adr/old-numbers.md).

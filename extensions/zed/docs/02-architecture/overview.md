# The Zed extension: its files

## The grammar (`grammar/`)

A tree-sitter grammar of tokens: comments, strings with `${}`, numbers, decorators, words, operators and nested
brackets. It never fails on half-written code. Zed reads a published extension's grammar from a git commit:
`[grammars.nuclear]` of `extension.toml` names the repository, the path and the `rev`. The installed extension
uses `grammar/nuclear.wasm`, which `build.sh` regenerates. The extension's own `repository` is the tree,
`nuclearlang/nuclearlang`; the grammar's is still `nuclearlang/nuclear-zed` (the roadmap).

## The language (`languages/nuclear/`)

| File | What it holds |
|---|---|
| `config.toml` | the indentation rules of VS Code; `documentation_comment` for ` * ` (Enter in a `//` continues with ` * `) |
| `highlights.scm` | the token colors; in Zed the later pattern wins |
| `brackets.scm`, `overrides.scm` | brackets and scopes |
| `semantic_token_rules.json` | the server's semantic tokens: `kind`, `defaultLibrary`, `deprecated` (struck through) |
| `tasks.json` | Nuclear: the generated code of a file, check; Synapsis: run, device, terminal device, test, build, watch, analyze, repair, explain |
| `runnables.scm` | ▷ on `main(` → `synapsis-main`; on `@test` / `@widget` / `@states("name")` → `synapsis-test` with `$ZED_CUSTOM_test_name` |

## The extension (`src/lib.rs`)

wasm32-wasip2 with `zed_extension_api` 0.7. It starts `nuclear-lsp` from `lsp.nuclear-lsp.binary.path`, the `PATH`
or `~/.local/bin` (the installed one, which finds dialects and type definitions in `share/nuclearlang`), and passes
it the user's `lsp.nuclear-lsp` settings as `{ nuclear: ... }`.

## Theme and icons

`themes/chernobyl.json` is generated by `../vscode/theme/build.mjs`; `icon_themes/` and `icons/` by
`scripts/icons.mjs` from `../vscode/icon-themes`.

## Code metrics

The server answers `nuclear.showCodeMetricsCodeLensInfo` with `window/showMessage` only for a client whose
`clientInfo.name` starts with `Zed`.

## What Zed does not allow

- The device inside the editor, `.nuc` debugging and build on save.
- Keybindings and views of an extension, so there is no Nuclear workspace (ADR-extensions-0002).

Nuclear Builder is not offered in Zed (decided by the user), and the project card is not shown.

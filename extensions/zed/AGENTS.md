# Zed extension

The NuclearLang extension for Zed (`nuclearlang`, 0.51.0): a tree-sitter grammar of tokens, the client of the
language server, the Chernobyl theme and icons, and the Synapsis tasks and runnables. What the three extensions
share: [`../AGENTS.md`](../AGENTS.md).

## Stack
- Rust → wasm32-wasip2 (`rustup target add wasm32-wasip2`), `zed_extension_api` 0.7; a crate of its own, outside the
  tree's Cargo workspace
- tree-sitter (`cargo install tree-sitter-cli`), needed only when `grammar/grammar.js` changes
- node, for the icons

## Commands
```sh
./build.sh      # builds AND installs into ${XDG_DATA_HOME:-~/.local/share}/zed/extensions/installed/nuclearlang
```

`build.sh` regenerates the parser and its wasm when `grammar.js` is newer than `grammar/nuclear.wasm`, runs
`scripts/icons.mjs`, compiles the extension and copies `extension.toml`, `languages/`, `themes/`, `icon_themes/`,
`icons/`, `extension.wasm` and `grammars/nuclear.wasm` into Zed. Zed reloads it by itself; if not, restart Zed.
`installer/install.sh` runs it when Zed is installed (`--no-zed` skips it).

## Folders
- `grammar/`: the tree-sitter grammar (`grammar.js`, `src/`, `nuclear.wasm`)
- `languages/nuclear/`: `config.toml`, the `.scm` queries, `semantic_token_rules.json`, `tasks.json`
- `src/lib.rs`: the extension (starts the server)
- `extension.toml`: the version, the grammar's commit, the language server
- `scripts/icons.mjs`: writes `icon_themes/` and `icons/` from `../vscode/icon-themes`
- `themes/chernobyl.json`: GENERATED by `../vscode/theme/build.mjs`
- `icon_themes/`, `icons/`: GENERATED by `scripts/icons.mjs`
- `target/`: generated

## Rules
- Never edit `themes/`, `icon_themes/` or `icons/`: change `../vscode/theme/` or `scripts/icons.mjs`.
- The grammar only knows tokens and never fails on half-written code: the meaning of a name comes from the server's
  semantic tokens, not from the grammar.
- In `highlights.scm` the later pattern wins.
- Zed has no bundle: the server is the installed `nuclear-lsp`.
- The version follows the VS Code extension's. After a change, release:
  [`../docs/06-runbooks/release.md`](../docs/06-runbooks/release.md).

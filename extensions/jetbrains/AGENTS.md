# JetBrains plugin

The NuclearLang plugin for Android Studio and IntelliJ (`dev.nuclearlang`, 0.52.0): the client of the language
server, the TextMate grammar and the Chernobyl themes of the VS Code extension, the code metrics, Synapsis projects
that work like a Flutter project, `.nuc` breakpoints, and two tool windows (*HTTP Connections*, *Nuclear Builder*),
whose code is in `../tools/nuclear-http-connections/jetbrains/src/` and `../tools/nuclear-builder/jetbrains/src/`. What
the three extensions share: [`../AGENTS.md`](../AGENTS.md).

## Stack
- Java (`javac --release 21`), compiled against the jars of the installed IDE; no Gradle
- The platform's native LSP API (`com.intellij.modules.lsp`, present in Android Studio 2026.2), the TextMate plugin
  bundled with the IDE; `since-build` 251
- Compiled against Android Studio 2026.2; never loaded in a running IDE
  ([roadmap](docs/01-product/roadmap.md))

## Commands
```sh
IDE_HOME=/opt/android-studio ./build.sh     # → build/nuclearlang-<version>.zip
```

`build.sh` needs `../vscode` beside it (the theme and the grammar), node and cargo. It generates the themes, builds
`nuclear-lsp`, writes `resources/codemetrics-defaults.json` from the server, compiles `src/` with every
`../tools/*/jetbrains/src/`, and zips the plugin
with the server, every dialect, the contract of each platform and the TextMate bundle. It ends with
`nuclear-lsp --check-bundle`.

Install: *Settings → Plugins → ⚙ → Install Plugin from Disk…* → the zip. Then *Settings → Appearance → Theme* →
**Chernobyl** (it includes the editor's color scheme). Only the color scheme: *Settings → Editor → Color Scheme → ⚙
→ Import* → `Chernobyl.icls`.

## Folders
- `src/dev/nuclearlang/editor/`: the plugin's own classes ([what each does](docs/02-architecture/overview.md)); the
  tool windows' classes are in the tools' folders
- `resources/META-INF/plugin.xml`: the version, the extensions, the tool windows, the actions and their shortcuts
- `resources/themes/`, `Chernobyl.icls`, `ChernobylSoft.icls`, `resources/icons/`: GENERATED by `../vscode/theme/`
- `resources/codemetrics-defaults.json`: GENERATED from `nuclear-lsp --codemetrics-defaults`
- `build/`: generated (the classes, the zip)

## Rules
- Never edit the generated themes, color schemes, icons or `codemetrics-defaults.json`: change `../vscode/theme/`
  or the server.
- The IDE manages `flutter run` and the language server's process itself: the plugin starts neither.
- The tool windows read the same files of a project as VS Code (`.nuclear/project.json`, `contract.json`,
  `http.json`, `builder/runs/*.json`, `specs/*/spec.md`); Nuclear Builder runs only through `nuclear-builder`.
- After a change, release: [`../docs/06-runbooks/release.md`](../docs/06-runbooks/release.md).

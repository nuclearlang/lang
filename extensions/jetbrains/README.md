# NuclearLang for Android Studio / IntelliJ

The NuclearLang plugin for JetBrains IDEs (`dev.nuclearlang`, build 251 or newer): the language server
`nuclear-lsp`, the TextMate grammar and the Chernobyl themes, code metrics, Synapsis mobile projects that work like a
Flutter project, `.nuc` breakpoints, and two tool windows, *HTTP Connections* and *Nuclear Builder*.

## Why it exists

A Flutter developer lives in Android Studio. The plugin lets a Synapsis mobile app be written in Nuclear there and
still run with everything the Flutter plugin gives: the device picker, Run / Debug, hot reload, DevTools. Opening
the project runs `nuclear build`; saving a `.nuc` builds and hot reloads the running app.

What it leaves out: Nuclear Atlas, the settings page, the notifications and the Nuclear workspace are VS Code only;
stepping by Nuclear line is not there yet ([roadmap](docs/01-product/roadmap.md)).

## How we made it

- **The same server and grammar as every editor**
  ([ADR-extensions-0001](../docs/03-adr/0001-one-base-extension-per-editor.md)): it uses the IDE's native LSP API
  (`com.intellij.modules.lsp`) and the TextMate plugin bundled with the IDE, with the grammar of the VS Code
  extension. The themes, color schemes and icons are generated by `../vscode/theme/`.
- **The IDE runs what it already knows how to run**: the plugin never starts `flutter run` nor the server's process
  itself; it adds the generated app (`build/app`) as a module and lets the Flutter plugin do the rest.
- **The tool windows read the same files as VS Code** (`.nuclear/project.json`, `contract.json`, `http.json`, the
  Builder's runs); Nuclear Builder runs only through the `nuclear-builder` command. Their code lives in
  [`../tools/nuclear-http-connections/`](../tools/nuclear-http-connections/README.md) and
  [`../tools/nuclear-builder/`](../tools/nuclear-builder/README.md).
- **Written in Java**, compiled with `javac` against the jars of the installed IDE: no Gradle.

**State:** compiled against Android Studio 2026.2, never loaded in a running IDE.

## Try it

```sh
cd extensions/jetbrains                       # beside extensions/vscode; needs node and cargo
IDE_HOME=/opt/android-studio ./build.sh       # → build/nuclearlang-<version>.zip, checked with nuclear-lsp --check-bundle
```

Then *Settings → Plugins → ⚙ → Install Plugin from Disk…* → the zip, restart the IDE, and *Settings → Appearance →
Theme* → **Chernobyl**. Open a Synapsis project folder (*File → Open*); the first time the plugin offers *Reopen
Project*, after which the Flutter plugin's devices and Run appear. The release does not ship the zip.

# Decisions of the code generator

Cited as `ADR-codegen-NNNN`. The format is `docs/03-adr/0000-template.md` of the tree's root. An accepted ADR is not
edited: a new one replaces it and the old one is marked `superseded by ADR-codegen-NNNN`.

| ADR | Decision | Status |
|---|---|---|
| [ADR-codegen-0001](0001-the-generators-write-finished-code-the-agent-only-what-is-not-standard.md) | The CLI and the MCP generate the standard code, finished and compiling, from the platform's templates; an agent writes only what is not standard | accepted |

A decision cited by its old platform-wide number (`ADR-00NN`, in code or commits before 2026-11-16): see
[the table of old numbers](../../../../docs/03-adr/old-numbers.md).
